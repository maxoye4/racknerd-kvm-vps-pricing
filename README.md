## 下单前必须知道的限制：退款、备份、Windows、降级

- **默认不退款，也没有试用。** 公开条款的梳理显示默认不退款，官方页面没有 30 天退款承诺。第一次用先买最小档，别一上来买 8 GB。
- **Unmanaged。** 工单管硬件、网络和平台，不管你代码、面板配置和数据迁移。需要人帮你搭环境，另找 managed 服务。
- **不能一键换机房。** 下单选定，事后换机房要重新买再迁移。
- **不支持降级。** 可以升级，重启一次，停机不到一分钟；降级不行。先买低配再升是安全的，反过来不行。
- **流量超限限速，不直接停机。** 3 到 20 TB 月流量对大多数轻量用途够用；超了端口限速，具体以条款为准。
- **Windows 要另买。** Linux 线默认只支持 Linux，Windows 是独立产品线。
- **IPv6 要工单申请。** 洛杉矶和法国可免费申请最多 100 个 IPv6 地址，其他机房陆续支持。
- **没有自动备份、快照或 API 的公开承诺。** ctrl 面板负责重启、重装、VNC、防火墙、一键应用和改 root 密码；重要数据自己备份。

**1 GB 特价跑 WordPress 够吗？**
轻量站够。插件多、流量上来、同时装缓存和统计插件，内存会吃紧，升 2 GB 特价 $35.99/年更稳。

第三方指南说特价线续费同价，官方 Specials 页没写死。下单页的 Renewal 金额最准，买之前看一眼。

**能换机房、能降级吗？**
不能一键换机房，要重新买再迁数据。能升级，重启一次；不支持降级。

**流量超了会停机吗？**
通常限速，不直接停机。具体以服务条款为准。

**支持 IPv6 和支付宝吗？**
洛杉矶和法国可开工单免费申请最多 100 个 IPv6。结账支持支付宝，实际可选方式以结账页为准。
